# REM PhysicalAI

**Robots that dream themselves better.**

> **Built for the Arduino Ventuno Q.** REM PhysicalAI was designed for —
> and runs on — the **Arduino Ventuno Q**, Arduino's Qualcomm-powered
> board for physical AI. The Ventuno Q is **not yet on sale**
> (pre-order only); REM PhysicalAI was developed and demonstrated on it
> at the ExecuTorch Hackathon (Founders, Inc., San Francisco,
> October 2026). When the board ships, REM PhysicalAI ships with it.

![A robot dreaming under the moon](system/banner.jpg)

## In 30 seconds

Robots leave the factory and never learn again. REM PhysicalAI changes
that — it is a small learning system that lives **inside the robot**:

- **It learns by itself** — it acts, watches the result, and improves.
- **It dreams** — while the robot sleeps, it rehearses in a physics
  simulation, retrains its own brain, and keeps the change only if it
  truly got better.
- **It wakes up better** — no cloud, no connection, nothing leaves the
  robot.

## What it does

- **Awake** — it understands its own body in real time (standing,
  walking, fallen, flipped) and acts on what it feels.
- **Teach** — show it a new pose or a photo; a person teaches, it learns,
  and it retrains itself on the spot.
- **Dream** — idle, it dreams in simulation: thousands of imagined
  experiences, generated by physics, that train its brain overnight.
- **Mirror** — it tests itself: it commands, watches itself, and grades
  what it saw. Learning is only real if the mirror agrees.
- **Voice** — it can say what it knows about itself, in its own words,
  generated on-device.

## Quick start (Ventuno Q)

```bash
git clone https://github.com/RemPhysicalAI/rem-physical-ai.git
cd rem-physical-ai
./quickstart.sh
```

Then open the dashboard: `http://<your-board>:8080`

## What's inside

- `system/` — the engine (robot-agnostic): interface, dream engine,
  teaching, vision, voice
- `dreamworld/` — the dream: the robot's twin in a physics simulation
- `examples/walkersense/` — a disposable example robot (a $1 walker body)
- `projects/` — one folder per robot running REM PhysicalAI
- `assets/` — the logo · `docs/` — the documentation

Any robot can host it — it needs only three plugs: a way to **act**, a
camera to **see**, and a computer to **think**.

## Status

Proven live on a real Ventuno Q at the ExecuTorch Hackathon
(October 17–18, 2026): on-device inference and control, a human teaching
it a new pose with on-device retraining in seconds, continuous dream
cycles while idle, a voice that reports its own state, and a dream that
is simulated live in your browser from data — no video stream.

Built with PyTorch + ExecuTorch + MuJoCo (all open source).
